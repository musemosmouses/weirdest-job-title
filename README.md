One original job title — the weirdest one we could think of. A real-sounding senior corporate role wrapped around one gloriously odd department: an executive who manages relations with geese, as if that were a normal line of work.

> Senior Vice President of Goose Relations

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 40 characters, within the 60-character cap.
